🎨 THEME SYSTEM

<vd-theme> NEW v4

Injects CSS custom properties (--vd-*) into :root. All VD components consume these tokens automatically. Place inside <body> before other VD components.

Attributes:

  • primary, secondary — main brand colors
  • background, surface, text, border
  • radius, shadow, font-family, transition
  • success, error, warning, info

💡 Use VdTheme.applyTokens({…}) to change tokens at runtime. Tokens are inherited by all components via CSS cascade.

Example
<!-- Optional: customize global theme tokens -->
<vd-theme
  primary="#667eea"
  secondary="#764ba2"
  background="#f5f5f5"
  surface="#ffffff"
  text="#333333"
  border="#dddddd"
  radius="8px"
  shadow="0 2px 8px rgba(0,0,0,0.15)"
  font-family="Inter, system-ui, sans-serif"
  transition="0.2s ease"
  success="#4caf50"
  error="#f44336">
</vd-theme>

<!-- Programmatic API (JavaScript) -->
<script>
  // Apply tokens dynamically
  VdTheme.applyTokens({ primary: "#ff6b6b", radius: "4px" });

  // Read a resolved token
  const color = VdTheme.getVar("primary"); // "#ff6b6b"
</script>
🧭 NAVIGATION COMPONENTS

<vd-radionav> + <vd-radiolink>

Navigation bar with radio-button style indicators. v4 adds role=radiogroup / role=radio + aria-checked + keyboard navigation.

vd-radionav attributes:

  • backgroundcolor, align (left/center/right), textcolor

vd-radiolink attributes:

  • url, textcolor, activecolor, shadowcolor
  • backgroundcolor, active (true/false), show-radio (true/false)

💡 v4 ARIA: radionav → role=radiogroup; radiolink → role=radio + aria-checked. Keyboard: Enter/Space selects.

Example
<vd-radionav backgroundcolor="#667eea" align="center" textcolor="white">
  <vd-radiolink
    url="page1.html"
    textcolor="white"
    activecolor="#764ba2"
    shadowcolor="rgba(0,0,0,0.3)"
    active="true"
    show-radio="true">Home</vd-radiolink>
  <vd-radiolink
    url="page2.html"
    textcolor="white"
    activecolor="#764ba2"
    shadowcolor="rgba(0,0,0,0.3)">About</vd-radiolink>
  <vd-radiolink
    url="page3.html"
    textcolor="white"
    activecolor="#764ba2"
    shadowcolor="rgba(0,0,0,0.3)">Contact</vd-radiolink>
</vd-radionav>

<vd-popnav> + <vd-poplink>

Horizontal navigation bar with hover pop-up (lift) effect. v4 adds role=navigation + role=menuitem.

vd-popnav attributes:

  • backgroundcolor, shadowcolor, align

vd-poplink attributes:

  • url, target, textcolor, hovercolor

💡 v4 ARIA: popnav → role=navigation landmark; poplink → role=menuitem. Keyboard: Enter activates link.

Example
<vd-popnav backgroundcolor="#333" align="center" shadowcolor="rgba(0,0,0,0.3)">
  <vd-poplink url="index.html"   textcolor="white" hovercolor="#667eea" target="_self">Home</vd-poplink>
  <vd-poplink url="about.html"   textcolor="white" hovercolor="#667eea" target="_self">About</vd-poplink>
  <vd-poplink url="contact.html" textcolor="white" hovercolor="#667eea" target="_self">Contact</vd-poplink>
</vd-popnav>

Modal confirmation dialog. v4 adds role=dialog + aria-modal + aria-labelledby.

Example

  backgroundcolor="#fff"

📄 FULL PAGE BOILERPLATE

Complete page template

Minimal boilerplate showing the correct load order and usage of <vd-theme>.

💡 Always place scripts at the end of <body>. Load order: utils → theme → global → macrocomponents. All paths relative.

Example

  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>My Page — VD Framework 4</title>
</head>
<body>

  <!-- 1. Theme (optional but recommended) -->
  <vd-theme primary="#667eea" secondary="#764ba2" radius="10px"></vd-theme>

  <!-- 2. Navigation -->
  <vd-popnav backgroundcolor="#333" align="center">
    <vd-poplink url="#home"  textcolor="white" hovercolor="#667eea">Home</vd-poplink>
    <vd-poplink url="#about" textcolor="white" hovercolor="#667eea">About</vd-poplink>
  </vd-popnav>

  <!-- 3. Layout -->
  <vd-structure orientation="landscape" backgroundcolor="#f5f5f5" textcolor="#333">
    <vd-sidepanel backgroundcolor="#fff" width="25%">
      <vd-colorcard backgroundcolor="#667eea" textcolor="white" width="100%">
        <h3>Sidebar Card</h3>
      </vd-colorcard>
    </vd-sidepanel>
    <vd-mainpanel backgroundcolor="#f9f9f9" width="75%">
      <h1>Welcome!</h1>
      <p>Main content area.</p>
    </vd-mainpanel>
  </vd-structure>

  <!-- Load scripts last — RELATIVE paths, correct order -->
  <script src="vd_framework_utils.js"></script>
  <script src="vd_framework_theme.js"></script>
  <script src="vd_framework_global.js"></script>
  <script src="vd_framework_macrocomponents.js"></script>
</body>
</html>
