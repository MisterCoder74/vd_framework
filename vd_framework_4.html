Circular profile-style badge. title = heading in top half, body text = bottom half, image = optional background image URL, width = diameter.

Alert (modal dialog)

<vd-alert> — Attrs: title, backgroundcolor, textcolor, width, height, duration
Hidden by default (display:none). Call .show() to display.
Optional duration (ms): auto-dismisses after the given time. Omit for manual dismiss.
v4 ARIA role=alert + aria-live=assertive + aria-label
This alert will disappear automatically after 3 seconds.

Confirmation Dialog

<vd-confirmation> — Attrs: title, backgroundcolor, textcolor, width, height
Hidden by default. Call .show() to display. Fires confirm event: detail.confirmed true/false.
v4 ARIA role=dialog + aria-modal + aria-labelledby
Are you sure you want to proceed? This action cannot be undone.
